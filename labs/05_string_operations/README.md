# Lab 5 — Manipulating Strings

Run `python string_operations.py` to see `strip`, `split`, slicing,
case helpers, f-string interpolation, and `count` / `startswith` over
a router hostname and a Cisco-style interface description.

## Expected output

```
short:      csr1kv1
last octet: 7
upper:      CSR1KV1
'up' count: 2
prefix Gi?  True
```
