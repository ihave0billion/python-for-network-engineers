# Lab 6 — Conditionals and Operators

Run `python conditionals.py` to classify a list of interfaces by their
`status` and `protocol` fields using `if / elif / else`, the `and`
logical operator, the `in` membership operator, and an inline
conditional expression.

## Expected output

```
Gi1/0: healthy (trunk)
Gi1/1: down
Gi1/2: layer-1 up, layer-2 down
Gi1/3: shut by admin
```
