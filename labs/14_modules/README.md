# Lab 14 — Python Modules and Packages

Run `python modules_demo.py` to see four stdlib modules in one place:
`sys` for interpreter info, `os.path.basename` for filename extraction,
`json.dumps` to serialize a dict, and `pathlib.Path` to assemble a
cross-platform path.

## Expected output

(Python minor version may differ — the rest is deterministic.)

```
python:      3.11
script:      modules_demo.py
device json: {"name": "R1", "loopback": "10.0.0.1"}
config dir:  /var/log/cisco/R1
```
