# Lesson 6 — Conditionals and Operators

## if / elif / else
Indentation defines blocks. `if` evaluates a Boolean expression. `elif` adds
mutually exclusive branches. `else` is the catch-all.

## Operator categories
- Arithmetic: `+ - * / ** % //`
- Assignment: `= += -= *= /= %= //= **=`
- Comparison: `== != > < >= <=`
- Logical: `and or not`
- Identity: `is`, `is not` (memory location)
- Membership: `in`, `not in`
